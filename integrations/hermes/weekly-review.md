# Optional weekly review

Read SCHEMA.md, index.md, and the relevant recent log. Ask the user what new
decisions, sources, and recurring questions should become durable knowledge.
Distinguish new captures from changes to existing synthesis. Propose concrete
pages to create/update and cite their sources. Do not manufacture a summary from
unavailable conversations or inspect unrelated accounts/projects.

After authorized edits, confirm each save, index update, and log entry. Report
unresolved contradictions or partial writes explicitly. Scheduling is optional;
the cloud-only user can run this same review directly in their LLM conversation.
